# SW2.5 Chat Palette Prefixer

『ソード・ワールド2.5』のキャラクターシート作成ツール（ゆとシート等）から出力されたチャットパレットテキスト内の変数に、一括でプレフィックス（接頭辞）を付与するCLIツールです。

Tekey等のオンラインセッションツールにおいて、複数PC（『エンシェントブルー』のバディ運用や魔物・NPC同伴など）のパレットを1箇所で管理する際の**変数名の衝突（バッティング）を防止**します。

---

## 主な特徴

- **外部ライブラリ不要**: Python標準ライブラリのみで動作します（追加の `pip install` 不要）。
- **2パス走査による安全な置換**:
  - `//変数名=値` で定義された変数を事前に収集してから置換するため、定義より前にある参照行や、`//器用={器用度}` のような右辺の参照も正確に追従します。
  - `{13}` や `{-1}` などのダイス計算用固定値や、コマンド記法は誤置換しません。
- **インデント・空白の保持**: 元のテキストの改行形式、行頭インデント、行末スペースを壊さずに維持します。
- **文字コード自動判定**: UTF-8（BOM付き/BOMなし）および Shift-JIS (CP932) の自動判別に対応。出力はUTF-8で統一されます。
- **誤変換ガード**: すでにプレフィックスが付与されているテキストを多重変換しない安全機構を備えています。

---

## 動作要件

- Python 3.8 以上

---

## 使い方

### 基本コマンド

引数に対象のテキストファイルを渡します。デフォルトでは接頭辞 `01` が付与され、`[元ファイル名]_01.txt` として保存されます。

```bash
python prefix_palette.py sample.txt
```

### プレフィックス・出力先を指定

`-p`（`--prefix`）で任意の接頭辞を指定できます。

```bash
# 接頭辞を '02' にする場合 (出力: sample_02.txt)
python prefix_palette.py sample.txt -p 02

# 接頭辞を 'A_' にし、出力ファイル名を明示する場合
python prefix_palette.py sample.txt -p A_ -o palette_A.txt
```

### オプション一覧

| オプション | 引数 | 説明 |
| :--- | :--- | :--- |
| `-p`, `--prefix` | 文字列 | 付与する接頭辞（デフォルト: `01`） |
| `-o`, `--output` | パス | 出力先ファイルパス（省略時は `[入力名]_[prefix].txt`） |
| `--all-refs` | - | パレット内で定義されていない参照（`{HP}` 等）も数値以外はすべて置換 |
| `--force` | - | 変換済みと思われるファイルでも警告を無視して強制変換 |
| `-h`, `--help` | - | ヘルプメッセージを表示 |

## 変換例

### 変換前 (`sample.txt`)

```text
### ■能力値
//器用度=22
//敏捷度=27

### ■代入パラメータ
//器用={器用度}
//器用B=(({器用}+{器用増強})/6)

### ■判定
2d+{冒険者}+{器用B} 冒険者＋器用
k10[13] 〈救命草〉
```

### 変換後 (`sample_01.txt` / `-p 01`)

```text
### ■能力値
//01器用度=22
//01敏捷度=27

### ■代入パラメータ
//01器用={01器用度}
//01器用B=(({01器用}+{01器用増強})/6)

### ■判定
2d+{01冒険者}+{01器用B} 冒険者＋器用
k10[13] 〈救命草〉
```
